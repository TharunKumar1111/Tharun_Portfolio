E-commerce Retail Sales Analysis

Python · MySQL · Power BI

Problem

Uber Trip Data Analysis

Python · SQL · Power BI

Problem

Raw June 2024 trip records needed a clear view of demand, fares and location performance.

Approach

Validated 103,728 trips and 265 locations in Python (Pandas), checking duplicates, missing values, invalid distances and unmatched location IDs. Defined 8 KPIs and 15 SQL business questions, then built a Power BI dashboard.

Outcome

Analyzed hourly and daily demand, top pickup and drop-off locations, vehicle categories, payment-wise revenue, fares and surge fees. Identified ways to improve driver allocation, efficiency and pricing.
